# Native starting packages

These are blank documents created by Pages, Numbers, and Keynote 14.4.1. They
provide the complete native style, table, slide-layout, and object graphs that
the applications require before semantic CRUD can begin. Finder previews were
removed because generated content would make them stale.

`litchi-iwa` never returns these packages verbatim. Every `create()` call
parses a fresh package and transactionally replaces its document, saved-version,
private, sharing, stable-document, and package-revision identities before the
editor is exposed.
