### Regenerating

The generator crate `litchi-iwa` was deleted by record 0429 (W3); check out
commit `802995d7b7` (or any commit up to `27b4840684`, the last one that
contains the crate) to regenerate.

1. In that checkout, build a throwaway program outside the repository, with
   its own target directory, depending on `litchi-iwa` by path:

   ```toml
   [package]
   name = "gen-keynote-blank"
   version = "0.0.0"
   edition = "2024"
   publish = false

   [workspace]

   [dependencies]
   litchi-iwa = { path = "<checkout>/crates/litchi-iwa" }
   ```

   ```rust
   fn main() {
       let path = std::env::args().nth(1).expect("usage: gen-keynote-blank <out.key>");
       let editor = litchi_iwa::keynote::Builder::new()
           .build()
           .expect("host Keynote builder");
       std::fs::write(&path, editor.to_bytes().expect("host Keynote bytes")).expect("write");
   }
   ```

   Run it (copying the checkout's `Cargo.lock` next to it) to write
   `raw-host.key` (9,667 bytes in the committed run).

2. Stamp the fixed identity with the crate's own identity rewrite:

   ```sh
   LITCHI_KEYNOTE_BLANK_SOURCE=raw-host.key LITCHI_KEYNOTE_BLANK_OUTPUT=blank.key \
     cargo test -p litchi-keynote --lib regenerate_blank_template -- --ignored
   ```

   The test rewrites `Metadata/Properties.plist`, `Metadata/DocumentIdentifier`
   and the package-metadata revision in `Index/Metadata.iwa`, reopens and
   validates the result, then writes it.

3. Replace `blank.key`, update the size and SHA-256 above, and run
   `cargo test -p litchi-keynote --test package_new`.
