# Excel Binary Workbook (.xlsb) Feature Matrix

This document tracks the public feature families implemented by litchi-xlsb. It describes
typed support for the BIFF12 binary parts and their OPC package, not Excel rendering,
recalculation, network access, macro execution, or complete conformance with every extension.

The audit uses the authoritative Microsoft [MS-XLSB] Front Matter and ToC, the file and
conceptual structures in [MS-XLSB] 2.1-2.2, and the examples for conditional formatting,
defined names, tables, filters, external references, formatting, workbooks, PivotTables,
metadata, and slicers in [MS-XLSB] 3.1-3.10.

## Status model

| Mark | Meaning |
|------|---------|
| ✅ | Supported for the scope described in the Notes cell |
| 🟡 | Bounded, partial, metadata-only, pass-through, or inert support |
| ❌ | No public typed support currently available |
| N/A | The concept does not apply to this format or direction |

Read and Write are independent. Typed records and package parts do not imply that
formula results are recalculated or that external, macro, or embedded content is run.
The ordinary workbook transaction, resource interning, shared-string, formula-dependency
rewrite, DrawingML authoring, and drawing-transfer paths locally deny the correctness lint families still
quarantined for legacy BIFF12 codecs; the parser span seam applies the same denies to the
new offset-producing method without pretending the whole legacy parser has been remediated.

## Package, BIFF12, workbook, and core data

| Feature | Status | Read | Write | Notes |
|---------|--------|------|-------|-------|
| OPC package and BIFF12 part graph | ✅ | ✅ | ✅ | Workbook, Package, relationships, content types, binary parts, and package saves are modeled over the OOXML package graph. |
| BIFF12 raw record codec | ✅ | ✅ | ✅ | litchi-xlsb::raw enforces BIFF12 kind and length encodings, distinguishes clean EOF from truncation, lends payloads, validates UTF-16 and Boolean fields, and writes checked records. |
| Workbook and worksheet binary streams | ✅ | ✅ | ✅ | Workbook, worksheet, chart-sheet, styles, shared-string, connection, external-link, pivot, table, and related BIFF12 streams are read and written through the package model. |
| Workbook and sheet directory | ✅ | ✅ | ✅ | Sheet names, order, indices, visibility, sheet lookup, and workbook lifecycle operations are typed. |
| Cell values and cached results | ✅ | ✅ | ✅ | Numbers, strings, shared strings, booleans, errors, blanks, serial dates, and style references are supported with checked binary encodings. For existing packages, bounded `cell_values::{Snapshot, Edit, Commit, Patch}` inventories all ordinary scalar and formula-result record families, including inert formula flags/token/ancillary data. It supports structural cell insertion/removal, length-changing inline/rich/formula-cache strings, shared-string and complete typed-style resource creation, exact RK and checked Xnum values, formula cache changes, and validated formula-token replacement without evaluation. The ordinary workbook root adds durable cross-workbook transfer with SST/rich-run font/style closure and semantic remapping of uniquely equivalent defined-name, external-name, sheet/XTI, and structured-table dependencies. Existing value edits retain their BIFF12 record family; explicit remove-plus-insert performs an intentional family change. Changed cell records, row column-span metadata, and expanding worksheet dimensions are rebuilt deterministically while unknown records remain byte-exact. Workbook publication reparses the complete candidate and validates style, shared-string, grouped-formula, name/XTI/table, and package dependency closure. Patches expose ordered semantic deltas plus exact stale-checked images, inverse/sequential/disjoint/three-way merge semantics, bounded versioned transfer, and bounded undo/redo history. Missing or ambiguous target formula resources and unknown token families are refused. |
| Shared strings | ✅ | ✅ | ✅ | Shared-string tables and cell references are decoded and emitted; rich data objects beyond the shared-string model are not claimed. |
| Formula tokens and cached formula values | 🟡 | ✅ | 🟡 | BIFF12 formula token models, formula references, table/pivot references, and supported formula text are available. Root-authored cells support every cached-result family, and dependency-bearing transfers rewrite parser-proven fixed-width name, XTI, external-name, and resident/external table indexes to uniquely equivalent target resources. Missing, ambiguous, Pivot-scope-incompatible, and unknown-token dependencies fail before publication. The formula surface is bounded and there is no Excel-compatible evaluator. |
| Array, shared, and dynamic-array formulas | 🟡 | ✅ | 🟡 | Supported array/shared formula records and cached values are retained in bounded form; modern spill calculation and dependency propagation are not implemented. |
| Defined names and named ranges | ✅ | ✅ | ✅ | Workbook and sheet-scoped names, name formulas, and validated named-range authoring are available. Formula-cell transfer remaps name indexes by case-insensitive semantic identity only when the target match is unique; it does not evaluate names or synthesize a missing definition. |
| Calculation properties | ✅ | ✅ | ✅ | The specified BrtCalcProp form and the bounded early-artifact option-tail form are read; canonical 26-byte output, mode, reference mode, iteration, delta, thread count, and recalculation flags are validated. |
| Styles, fonts, fills, borders, alignment, and number formats | ✅ | ✅ | ✅ | Typed style tables, cell formats, differential formats, fonts, colors, borders, fills, alignment, and number formats are supported. |
| Workbook and worksheet views | 🟡 | ✅ | 🟡 | Sheet views, panes, selections, zoom, tab/window metadata, and chart-sheet views have typed coverage; all producer-specific view extensions are not modeled. |
| Merged cells | ✅ | ✅ | ✅ | Worksheet merge ranges have checked read and CRUD operations, including lookup by sheet name. |
| Row and column layout | ✅ | ✅ | ✅ | Row/column dimensions, hidden and collapsed state, outline levels, widths, heights, and supported worksheet defaults are available. |
| Core/package properties | 🟡 | 🟡 | 🟡 | Generic OPC package editing is public; there is no broad XLSB-specific typed property facade comparable to the binary package and workbook models. |

## Worksheet features

| Feature | Status | Read | Write | Notes |
|---------|--------|------|-------|-------|
| Worksheet cell CRUD | ✅ | ✅ | ✅ | Typed worksheet snapshots and writer models support cell insertion, lookup, value changes, and sheet serialization. |
| Hyperlinks | ✅ | ✅ | ✅ | BIFF12 hyperlink targets, display/location metadata, and bounded authoring are supported; links are never followed. |
| Classic comments and notes | ✅ | ✅ | ✅ | Worksheet comment records have a typed model and writer support. Comment text and anchors are data only. |
| Threaded comments and persons | ✅ | ✅ | ✅ | Contextual `comments::threaded::{Snapshot, Transaction, Commit, Patch}` owns bounded people/thread/mention metadata, worksheet relationship validation, source-checked CRUD, exact no-op replay, and inert package publication; collaboration services are never contacted. |
| Data validation | ✅ | ✅ | ✅ | Validation ranges and supported rule/formula forms are read and written through the worksheet/package writer. |
| Conditional formatting | ✅ | ✅ | ✅ | Classic rules, differential formatting, formulas, ranges, icon sets, color scales, data bars, and implemented extension/FRT forms are validated and serialized. Formulas are not evaluated. |
| Sparklines | ✅ | ✅ | ✅ | `sparkline::{Snapshot, Edit, Commit}` strictly parses and emits the Worksheet ABNF (§2.1.7.62) block formed by `BrtBeginSparklineGroup` (§2.4.228), `BrtBeginSparklineGroups`/`BrtBeginSparklines` (§2.4.229-230), their end records (§2.4.581-583), and `BrtSparkline` (§2.4.806). The shared `SparklineType`, `AxisType`, and `EmptyCells` enums are owned by `litchi-sheet`; XLSB owns the bounded BIFF12 model and formula-shape checks. A source-bound `Commit` carries an exact before-image guarded patch, but its raw patch is deliberately not public or nameable: publish it atomically only through `Workbook::apply_sparklines`. `Workbook::{sparklines, edit_sparklines, apply_sparklines}` contextually validates names/XTI indexes only against already-loaded, bounded workbook metadata; it never follows targets. `Worksheet` exposes parsed groups, `MutableWorksheet` atomically replaces or clears authored groups, and the new-workbook writer emits supported groups after final context validation. Source `PtgNameX` groups are preserved inertly, but a new writer refuses them because it cannot author the required external-workbook `BrtExternSheet` entry. `Limits` bounds the complete worksheet source ingress (512 MiB by default), groups, per-group and aggregate items, formula token/ancillary bytes, record bytes, and total block bytes; zero bounds are rejected and the block bound cannot exceed the worksheet-source bound. There is no formula evaluation, external-name resolution, target fetch, DDE/OLE activation, macro/control execution, or rendering. |
| AutoFilter, filter criteria, and sort state | 🟡 | ✅ | 🟡 | Worksheet AutoFilter and criteria metadata are modeled; the complete Excel filter UI and every producer extension are not a semantic engine. |
| Structured tables | ✅ | ✅ | ✅ | List/table identity, ranges, columns, header/totals metadata, style IDs, typed totals functions, inert calculated-column formulas, and worksheet wiring are serialized. Resident and external structured-reference formula transfers remap XTI and table IDs by resolved table/column semantics, refusing missing or ambiguous targets. |
| Page setup and print metadata | 🟡 | ✅ | 🟡 | Supported worksheet and chart-sheet page setup, margins, paper, scale/fit, orientation, print flags, and relationships are bounded; printer-driver/rendering behavior is not implemented. |
| Sheet protection | 🟡 | ✅ | 🟡 | Worksheet and chart-sheet protection flags and the supported strong-protection metadata are typed. Protection is not a cryptographic authorization boundary. |
| Scenarios and what-if analysis | 🟡 | ✅ | ✅ | `litchi_xlsb::scenarios` exposes bounded `BrtBeginScenMan`/`BrtBeginSct`/`BrtSlc` snapshots and transactional worksheet replacement. Known metadata is typed; unknown records and source order are retained, unsafe or ambiguous edits are refused, and scenario values are never substituted or recalculated. |
| Cell watches and phonetic metadata | ✅ | ✅ | ✅ | `[MS-XLSB]` 2.4.21, 2.4.331, 2.4.378, and 2.4.744 are exposed as typed worksheet cell-watch collections and worksheet-wide phonetic defaults with bounded, source-checked transactional edits; watch-window monitoring, phonetic rendering, and language conversion are not performed. |
| Shared-workbook revision records | 🟡 | ✅ | ✅ | `shared_workbook::{Snapshot, Transaction, Commit, Patch}` owns bounded user, header, and inert revision-log metadata with package relationship validation, source-checked CRUD, unknown-record retention, and failure atomicity; collaboration, locking, conflict resolution, and recalculation remain inactive. |

## Charts, drawings, pivots, and package objects

| Feature | Status | Read | Write | Notes |
|---------|--------|------|-------|-------|
| Chart sheets | 🟡 | ✅ | 🟡 | Chart-sheet names, visibility, views, protection, page setup, colors, and selected chart-resource relationships are modeled; this is not a complete chart grammar or renderer. |
| Embedded charts and chart resources | 🟡 | ✅ | 🟡 | Bounded chart resource discovery, embedded chart relationships, and selected OOXML chart/pivot-chart payloads are available. The durable workbook root transfers ordinary chart anchors with compact semantics-preserving chart XML, byte-exact binary resources, collision-safe part/relationship remapping, bounded inert external relationships, and closed relationship-free `/xl/` package resource leaves. Escapes to workbook, styles, shared strings, calculation chain, or sheet stories and non-chart graphic frames are typed refusals; arbitrary chart edits and full chart authoring are not claimed. |
| Worksheet drawings and anchors | 🟡 | ✅ | ✅ | Typed drawing/anchor inventories, image relationships, and supported shape resources are available. The durable workbook root can create a standard drawing or append image, chart, shape, nested-group, and connector-closure anchors to an existing drawing while retaining every prior DrawingML byte and relationship. Drawing-level MCE is reduced to its active supported branch for selection while untouched source bytes remain preserved. Incoming non-visual IDs, colliding names, relationship IDs, and chart resource URIs are remapped deterministically; connector endpoints pull in their referenced ordinary anchors, and shape-owned external hyperlinks, images, inert OLE objects, and embedded package leaves are copied with collision-safe relationship remapping. Pictures also use the separate image transfer API. Mixed Strict/Transitional conformance, ambiguous IDs, unresolved endpoints, active/unknown dependencies, and graph escapes are typed refusals. Legacy comment drawings coexist unchanged; arbitrary geometry editing and rendering are not performed. |
| Images | 🟡 | ✅ | ✅ | Supported image formats can be read, durably authored, appended to existing drawings, and transferred with encoded bytes, format, target anchor, alternative text, media part, and strict/transitional relationships. No image renderer or Office layout engine is included. |
| OLE and embedded package objects | 🟡 | ✅ | 🟡 | Bounded inventory recognizes worksheet, macro-sheet, dialog-sheet, and external-link object policies. Closed drawing-owned inert OLE/package leaves participate in anchor transfer with exact payload bytes and remapped relationships; general binary object creation and activation are not implemented. |
| Pivot caches | ✅ | ✅ | ✅ | Typed inert PivotCache definitions cover refresh metadata, worksheet/consolidation sources, all shared-item value kinds, range/discrete grouping, OLAP hierarchies and tuple caches, calculated items/members with inert formula tokens, and supported Excel extensions. |
| PivotTable views | ✅ | ✅ | ✅ | Pivot views, fields, items, layouts, data fields, filters, and workbook cache-ID wiring are read and serialized with lossless-or-refuse validation. No pivot refresh or calculation is performed. |
| Pivot charts | 🟡 | ✅ | 🟡 | Pivot-chart resources and relationships are recognized through the chart package model; chart rendering and full pivot-chart authoring are bounded. |
| Slicers and slicer caches | 🟡 | ✅ | ✅ | `slicer::{Snapshot, Transaction, Commit, Patch}` provides bounded, source-checked inert cache/view CRUD over native/table BIFF12 definitions and workbook/sheet relationship wiring. Commits validate cache-name dependency closure, exact no-ops preserve source bytes and signatures, changed publication is clone-staged with typed readback, stale patches are refused, and inverse patches restore the exact package source, including signature state. OLAP item-range authoring and filter execution remain outside this slice. |
| Timelines | 🟡 | ✅ | ✅ | `timeline::{Snapshot, Transaction, Commit, Patch}` provides bounded, source-checked inert CRUD over compact cache/view XML and BIFF12 workbook/sheet relationship wiring. Commits validate cache-name dependency closure, exact no-ops preserve lexical XML and signatures, changed noncanonical XML is refused rather than normalized, changed publication is clone-staged with typed readback, stale patches are refused, and inverse patches restore the exact package source, including signature state. Extension payloads, active filtering, and refresh remain outside this slice. |

## External references, connections, and extensibility

| Feature | Status | Read | Write | Notes |
|---------|--------|------|-------|-------|
| External workbook links | ✅ | ✅ | 🟡 | `external_link::{Snapshot, Transaction, Commit, Patch}` adds source-checked workbook/DDE/OLE metadata, external-name, flag, and cached-matrix edits while preserving opaque BIFF12 records and validated relationship topology; unsupported link forms are refused. |
| External formulas and cached values | 🟡 | ✅ | 🟡 | The five permitted external token structures and checked Xnum/worksheet-dimension rules are covered. Paths, names, formulas, and cached values are inert and are never resolved or recalculated. |
| DDE and OLE links | 🟡 | ✅ | 🟡 | DDE/OLE topics, program IDs, flags, and items are typed metadata only; no conversation, COM activation, refresh, or external launch occurs. |
| External data connections | ✅ | ✅ | ✅ | `host::connections::{Snapshot, Transaction, Commit, Patch}` adds source-checked create/update/remove and parameter edits over the BIFF12 External Data Connections part, preserving opaque records and OPC graph topology. Connection strings, commands, URLs, paths, and credentials are never contacted or executed. |
| Query tables and web imports | 🟡 | ✅ | 🟡 | Connection/query-table metadata is bounded and inert; no network fetch, import, refresh, or credential use is performed. |
| Custom XML Maps catalogs and BIFF12 bindings | 🟡 | ✅ | ✅ | `xml_maps::{Snapshot, ReadLimits}` reads the shared typed `XmlMapInfo` catalog plus ordinary-table `ColumnBinding` and per-worksheet `SingleCellBinding` metadata for [MS-XLSB] §§2.1.7.15, 2.1.7.46, 2.4.202/555, 2.4.104/458, and 2.5.170/171. `ReadLimits` composes caller-selected common `XmlMapLimits`, per-part BIFF `Limits`, core/package ceilings, and workbook-aggregate binding-count and UTF-16 XPath-unit ceilings. The common codec applies Office collection, unique ID/reference, string, bounded opaque-XML, and file-binding constraints; MapInfo readers accept only the canonical Office Boolean words `true`/`false` for required map flags and optional `FileBinding`, reject numeric `1`/`0`, and canonical writers emit `true`/`false`. The allowed but unmodeled `SchemaLanguage` attribute is ignored semantically and retained by same-conformance source patches when unchanged; canonical/new serialization omits it. XLSB additionally checks list IDs in `1..=0xFFFFFFFE`, column/map IDs, `XmlDataType`, cell coordinates, Boolean `crwHeader`/`crwTotals` values, and the supported absolute XPath lexical syntax. XPath validation is syntactic only: it recognizes QName child steps, an optional immediate named-attribute equality predicate, and an optional final attribute step, without schema, namespace, node-type, result, or evaluation processing. `Workbook::xml_maps[_with_limits]` requires exactly zero or one internal workbook-owned MapInfo relationship, matching Strict/Transitional relationship and root-namespace conformance, validated content types, relationship-free MapInfo and Single Cell Tables parts, and binding map IDs present in the catalog. It globally rejects tableSingleCells relationships from non-worksheets, shared targets, orphan Single Cell Tables parts, multiple parts per worksheet, external relationships, missing/wrong/orphan `BrtListPart` table relationships, duplicate list IDs across ordinary and single-cell tables, XML bindings to missing table columns, invalid/out-of-`BrtWsDim` ranges when the dimension is authoritative, pairwise ordinary-table overlap, ordinary-table overlap with the worksheet AutoFilter, tables whose height does not exceed Boolean header plus totals rows, and single-cell overlap with any ordinary table or AutoFilter. MapInfo `DataBinding/@ConnectionID`, XML-table `dwConnID`, and nonzero single-cell `dwConnID` are inert identifiers whose referenced External Data Connection must exist; a non-XML table cannot carry nonzero `dwConnID`, and no connection is contacted or refreshed. `WorkbookWriter::{set_xml_maps, xml_maps, clear_xml_maps}` (and aliases) plus `MutableWorksheet` mapped-table and single-cell set/get/remove/clear APIs stage `/xl/xmlMaps.xml`, supported `BrtBeginListXmlCPr` blocks on existing `Type::Xml` table columns, and at most one canonical single-cell part per worksheet only after the same applicable catalog/connection/Boolean/range/data-row/list-ID/pairwise-overlap/AutoFilter/size preflight; canonical single-cell output uses `dwConnID=0`. `Snapshot::edit` is failure-atomic and can create/replace/remove the catalog when dependencies allow, rename/edit maps, switch conformance when a catalog exists, add/replace/remove column bindings only within an already mapped XML table, and add/replace/remove bindings only within an already present Single Cell Tables part. Each draft and commit reuses the snapshot's caller-selected common XML, per-part BIFF, aggregate binding, aggregate XPath, and authored-output limits. Transactions do not create/remove a Single Cell Tables part, add the first binding to an otherwise unmodeled table, or remove an ordinary table part. `Commit`/`Patch` is bound to exact owned semantic state, bytes, content types, relationships, and topology; stale application is refused, exact no-ops preserve bytes and signatures, changed publication is clone-staged through full workbook reparse and removes signatures, and inverse application restores owned data/topology but never signatures. Because the vendored §2.1.7.46 conversion contains a build-path placeholder instead of `Biff12SingleCellTablesGrammar.abnf`, the reader accepts bounded opaque/FRT records around the known minimum structural sequence without claiming the missing grammar. Exact no-ops retain all source bytes. For ordinary tables, unrelated bytes and ignored/reserved `BrtBeginListXmlCPr` flag bits are retained across supported changes, while a changed opaque XML-property block is refused; canonical/new encoders emit those bits as zero. For Single Cell Tables, extra list/XML-property flag bits and valid but unmodeled connection/totals-function/label metadata are read inertly and preserved unchanged, but mark the source noncanonical so any changed edit is refused; opaque/FRT single-cell changes are likewise refused, while canonical output zeros ignored/reserved bits. There is no mapped XML import/export, schema/XPath/XML evaluation, resolution, synchronization, or instance processing; no Custom XML Data Storage processing or external access; and no formula, macro, or control activation/execution. |
| Ribbon and custom UI parts | 🟡 | ✅ | 🟡 | Ribbon families and bounded XML payloads can be inspected, replaced, and removed through package APIs; UI behavior is not executed. |
| Task panes and web-extension bindings | 🟡 | ✅ | 🟡 | Task-pane graphs and worksheet binding metadata have bounded package support; `package::web_extension_bindings::{Snapshot, Transaction, Commit, Patch}` adds source-checked BIFF12 binding edits. Add-in activation and provider-specific behavior are not implemented. |
| VBA project and code modules | 🟡 | 🟡 | ✅ | vbaProject.bin CFB/MS-OVBA project/module payloads and legacy/Agile signature-part metadata can be inventoried and authored with bounded project operations. Source is never executed or trusted; replacement drops stale project signatures. |
| OPC digital signatures | ✅ | ✅ | ✅ | Workbook signing, re-signing, verification, and unsigning are exposed through the OPC signature integration. Verification establishes integrity/signature validity only, not certificate trust or revocation. |
| Password encryption | ❌ | ❌ | ❌ | Package encryption/decryption is not implemented. Password-encrypted XLSB uses an OLE/CFB wrapper while current package ingress accepts OPC ZIP only; worksheet/workbook protection metadata is not package encryption. |
| Generic package part editing | ✅ | ✅ | ✅ | The underlying OPC graph can edit parts and relationships transactionally, including pass-through payloads. Typed XLSB models still refuse unsafe or semantically unknown mutations. |
