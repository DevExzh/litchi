# Change 0226: ODT file-source-open layout noise floor calibration (methodology)

Date: 2026-08-19

## Purpose

Not a code change — a measurement-methodology calibration, the direct
analog of 0223 (itself the litchi-odt analog of 0205/0213/0218),
completing the floor set for `odt_file_source_open` p50/mean, which 0223
left uncalibrated (no adverse-both evidence at the time). Change 0225
(ODT text-path resolution memo) was blocked by a residual adverse
both-directions p50 reading on the byte-identical guardrail phase
`odt_file_source_open` (primary max 6.65%): 0225 touches only the text
extraction path, which the source-open phase never executes, so the
reading had no code mechanism — but under the pre-floor rule an
uncalibrated statistic cannot be dismissed. Following the 0217→0218
precedent (calibrate before verdict), the verdict was deferred and this
calibration measures the phase's layout noise floor directly: binaries
whose source differs from the banked control (0224 state) only by
never-executed, parser-shaped padding code in litchi-odt, retained in
the binary via a `#[used]` function-pointer table.

## Floor rule (verbatim from 0223)

For each statistic, collect every paired reading where BOTH directions
are adverse (reduction < 0 in both a1→b1 and a2→b2). Probe readings and
historical adverse-both readings on byte-identical phases fold into the
same maximum (the 0205/0213/0218 method). The floor is the worst
observed adverse magnitude — max over readings of max(|d1|, |d2|) — with
NO additional margin, displayed at one decimal. Statistics with no
adverse-both evidence stay uncalibrated and the pre-floor rule still
applies to them.

Historical fold-ins (byte-identical phase for 0225, which touches only
the text path): primary 0225 p50 -6.65%/-0.28% and rerun 0225r mean
-0.04%/-4.57%, p99 -2.73%/-4.90%. Disagreeing pairs excluded: primary
mean -7.23%/+0.55%, primary p95 -12.10%/+1.99%, primary p99
-10.95%/+15.64%, rerun p50 +0.13%/-4.20%, rerun p95 +0.12%/-4.25%.

## Effective floor for `odt-file-source-open`

| Phase | p50 | mean | p95 | p99 |
|---|---:|---:|---:|---:|
| file-source-open | 6.7% | 6.1% | 45.0% | 38.7% |

The p50/mean entries calibrate statistics 0223 left uncalibrated; the
p95/p99 entries SUPERSEDE 0223's 2.5%/28.0% — probe c's tail readings
(45.02%/38.69%) exceed them, and the rule folds worst observed readings.
This session's machine was far noisier in the 500-sample nearest-rank
tails than the 0223 session's (0223 probes observed p99 at most 10.22%
on this phase). The 0223 lifecycle (3.8/2.5/4.0/6.5) and eager-open
(5.6/5.7/9.3/9.2) floors are unchanged. Scope limits as in 0218 rule 4:
calibrated on litchi-odt with binary text deltas of +3.9KB to +7.7KB;
substantially larger deltas, other crates, or protocol changes require
recalibration.
