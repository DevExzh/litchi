# Change 0134: ODS source-backed ordered cell-batch sweep evidence

Status: harnessed for matched query/source-read evidence; no release
performance acceptance claim.

This change adds the opt-in selectors:

- `ods_file_eager_cell_batch_sweep`
- `ods_file_source_cell_batch_sweep`

Both selectors use the exact scalar-sweep corpus: two worksheets with a
32-by-32 deterministic cell grid each, plus eight incompressible 2 MiB
`Pictures` payloads. The archive is generated by
`ods_media_rich_corpus_v1`; the smoke archive is 16,790,689 bytes with SHA-256
`46b7f61cb74639115f6d120dc6498b97d6b310d51c78c4fb85ac60d6fc758b14`.

## Timed scope

The owner and 2,048 borrowed `CellSelector` values are prepared before the
timer. Each warmup/sample timer contains only four bounded
`cell_batch(&selectors)` calls. Each returned vector is black-boxed, for 8,192
result slots per sample. Digesting, reopening, archive/member/media checks,
and source replay are outside the timed interval.

The batch digest preserves the scalar sweep's row-major selector order and
result cardinality, and is checked against both the eager scalar and eager
batch digests. The production batch bound remains 4,096 selectors; this
evidence uses 2,048 selectors and does not allocate beyond the bounded result
and sample collections.

## Source replay and preservation gates

For each source-backed sample, the fully prepared instrumented source is reset
before an independent four-call replay. Each `cell_batch` call performs one
source-version observation before lookup and one after lookup, so the replay
must report exactly eight version observations. It must also report zero
post-preparation payload `ReadAt` calls, zero payload bytes, and zero overlap
with the replay range. Ordered cardinality/digest parity and source archive
SHA, member topology, manifest media type, and retained-media payload identity
are checked outside timing. The source is never mutated during the replay.

## One-sample release smoke

The release smoke was run with:

```text
cargo run --release --locked --manifest-path tools/perf-baseline/Cargo.toml -- \
  --case ods_file_eager_cell_batch_sweep,ods_file_source_cell_batch_sweep \
  --warmup 0 --samples 1 --json /tmp/ods-cell-batch-smoke-0134.json
```

Both cases reported 2,048 selectors, four batch calls, 8,192 result slots,
2,048 stored cells, and digest
`90787d44304c04947f4431948fdfc56b795a28b1d25301eb37c6fa7226655c3b`. The
latest single observed elapsed samples were 42,709 ns eager and 61,925 ns
source; these are exploratory values, not a speed claim. Source preparation
reported 20 calls / 7,785 bytes, while the post-preparation replay reported 0
calls / 0 bytes / 0 overlap and 8 version observations. A clean release ABBA
run is required before making any latency or resource claim.

The two selectors are opt-in, bringing the selectable matrix to 257 while the
default remains 36 cases / 198 records.
