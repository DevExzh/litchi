## Reproduction and scope

`run.py` builds the existing, unchanged `managed_paragraph_batch_perf` example
with the pinned Rust toolchain and the settings in each build receipt. Its
source hash matches the 0500 final harness. Run `run.py` at the baseline source
and `run.py --variant candidate` at the candidate source. The scripts use the
explicit owned scratch paths recorded in `start.json`; recreate those paths
before reproduction. `capture.py` runs a named lane serially on CPU 2. The
frozen `plan.json` describes the baseline; `candidate-plan.json` records the
hypothesis before production edits and candidate captures. Each output is
exclusive: use a new evidence directory for a new campaign.

The native 24-case matrix spans 128/512 paragraphs, 1/8/32 replacements,
owned/warm-file input and repeated/batch editing. Each case has two internal
repetitions of three warmups and 30 measurements. Two fresh campaigns use
opposite case order. All rows retain exact-output, semantic readback,
untouched logical-member, source-version, forward/inverse preflight and
managed release checks. GNU time RSS is a whole-child maximum, not a phase
peak or allocator measure. Budget charges are not allocator counters.

Callgrind uses collection off at startup, toggles on function entry and back
off on return, and zeros at `run_sample`. One measured call remains after two
preflight calls. Two fresh processes per arm record publication-method Ir;
this excludes setup, edit, commit, caller destruction of the returned snapshot,
and post-output oracles. Native `publish_ns` includes that returned-snapshot
destruction. Instrumented CSV timings and RSS are excluded from native claims.
The six hardware captures are whole-child supplements, including setup and
oracles. They are not publication-local attribution or candidate comparisons.

A same-route comparison of current baseline and candidate is distinct from
batch-versus-repeated API choice. Historical 0500 timings used a different host
capture context and cannot establish causal closure of its flags. Each
individual regression and repeated-campaign variability remains visible.
