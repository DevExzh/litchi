# Provider and sink observations

This archive preserves three repeats of six provider/sink scenarios and the 201-row default registry from source `cab92a6bbc2f2eb09081c69ce90ba7bb29509155`. Each row contains 15 measured samples after three warmups. These are observations, with no performance-gain claim.

Extract `evidence.tar.zst` and run `python3 tools/verify_capture.py` from the extracted bundle directory. The standalone verifier checks all 621 rows, raw vectors, aggregate statistics, exact default registry, catalog identity, and build provenance. Root also verified a fresh extraction and its file checksums.

Corpus evidence establishes identity only; it does not reproduce generated bytes. Cold-requested filesystem reads are advisory, range reads are simulated, and physical counters do not attribute exact device I/O. The bundled README describes these limits and the exact source, runner, binary, and capture receipts.
