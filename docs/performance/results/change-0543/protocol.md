# 0543 XLSX shared traversal with validated completion

This campaign follows the rejected 0542 candidate and its prepared correction.
OLE2 and OOXML performance remain the user priority; ODF is deferred until that
goal completes, and iWork is excluded. The previous turn made progress by
committing the refusal harness, rejected experiment, independent review and
sealed evidence. No 0542 timing is reused as evidence for this implementation.

The hypothesis is that sharing the XML reader between independent validator
and parser states removes duplicate successful traversal, while forwarding
post-EOF materialization errors avoids the repeated work that failed 0542's
late-raw guard. Early validator, parser, reader and cap failures still drop
provisional state and take the authoritative validation-first fallback.
Original-source eligibility, resource limits, cancellation, source identity,
no-op sharing and publication checks remain required.

Public post-EOF materialization regression tests run unchanged on the fresh
baseline and candidate. The full 0541 error-order matrix and candidate cap tests
remain required. Test sources and patches are retained with the source
manifests. The existing standalone guard is unchanged between both builds;
its 96x96 and 128x128 fixtures are distinct from the main CRUD corpus.

Root owns all Rust builds and benchmark children, running them serially. Agents
may prepare code only in isolated owned paths while a measured source is frozen.
Every source attempt and failed command remains identified, with its exact
inputs, stdout/stderr and receipt; no measurement receipt may be overwritten.
Retained baseline binaries can run under the separately hash-bound candidate
checkout for the final ABBA repeat. All captures are fresh.

The original primary, allocation and refusal gates are unchanged. Every shape
and repeat must satisfy workflow p50/mean and planning p50 thresholds; ordinary
planning bytes and incremental peaks must meet the frozen allocation envelope.
Invalid planning p50 and incremental peak use the same-shape valid baseline
denominator, and same-invalid changes remain reported and individually reviewed.
Speculative parsing before a late validator failure is an explicit tradeoff,
not presumed fixed by the materialization correction. Instrumented timing is
not a native latency measurement; Region peak is not process RSS or an OOM proof.

If the pilot passes, paired planning instruction profiles and ordinary eager
read controls are required before retention. Whole-child hardware counters are
diagnostic. Every adverse or repeat-drift flag above five percent receives an
individual disposition; correlated flags are not independent experiments.
Final quality checks, source review and read-only evidence replay precede the
runtime decision. A rejected candidate is restored exactly while useful tests
and measurement enablers may remain. The sole owned target tree is removed
after all child processes finish and evidence is verified. Bundle writers stop
before sealing; staged bytes must match the final seal before committing.
