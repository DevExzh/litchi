# Evidence packet for change 0652

Record: [`docs/performance/0652-owner-decisions-for-the-third-wave.md`](../../0652-owner-decisions-for-the-third-wave.md).

A decision record has no measurement. This packet holds the decision record's
`decision.json` and the four log paragraphs the coordinator inserted at the top
of `HOTSPOTS.md`, `GOAL_AUDIT.md`, `REPORT.md` and `ADR_COMPLIANCE.md`.

| file | what it is |
| --- | --- |
| `decision.json` | The `litchi-perf-change-decision` record: what was decided, what it authorizes, what remains to be proved by the implementing records. |
| `log-sections.md` | The four log paragraphs. |

The owner's decisions are quoted verbatim in the record. The ADR index and the
status lines of ADR 0030 and ADR 0031 were changed in the same commit as the
record.
