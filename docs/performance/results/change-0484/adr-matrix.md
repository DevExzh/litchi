maps the accepted ADR set; it does not amend those records. The prior ADR
hashes are unchanged in [`adr-refresh.json`](adr-refresh.json). The current
contract review is cleared, while the overall evidence bundle remains
unsealed.

Each unchanged-source marker applies to its own receipt. The runtime and ASAN
receipts precede the formatting-only import/wrapping delta checked by dev76;
dev77 checks the final post-format source. The [checkpoint](docx-stream-checkpoint.md)
records this scope and does not assert an exact-byte runtime seal after formatting.

The receipts support these correctness statements only. The formal measurement
plan still needs independent source-size/authored-size, deterministic/store,
input-adapter, sink-size, compression, allocation, and peak-resident-memory
arms. In particular, a `MemoryReplayStore` retains bytes proportional to its
selected authored replay ceiling, and an external or durable store may retain
unknown caller-owned data; the fixed-window claim covers package-owned
operation windows, not all process memory. No production path creates an
ambient plaintext temporary file, filesystem provider, network client,
executor, or global cache for replay.
