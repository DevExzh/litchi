# 0782 observer audit

`observe.py` is the pure offline hook for the 0782 observer lanes. `analyze(packet)` reads and hashes retained receipts and reports; it does not start a capture, invoke a profiler, write `observer-analysis.json`, or hash its own source. The packet path may be passed explicitly so the same audit can be replayed after the owned worktree and target are removed.

The 0782 observer plan fixes CPU 12, three alternating `perf stat` blocks, the `payload/write` and `payload/lifecycle` cases, 30 samples plus three warmups, and `instructions:u,cycles:u`. The hook requires exactly 12 whole-process receipts, checks every command token and binary identity, validates every report sample, semantic readback, direct untrimmed text-atom oracle, and deterministic publication output, then pairs the before/after counters by block and operation. These counters include probe setup, publication, reopening, and verification. They do not isolate the timed operation and carry no timing-causality claim.

Each Heaptrack lane is one `payload/write` process with three samples and no warmup. Root must retain a decode receipt for the exact command `heaptrack_print -f trace.zst -H histogram -n 15 -s 3`, plus the raw trace, histogram, and print log. The parser streams the retained `.zst` through offline `zstd`, reconstructs string, instruction, inline, and parent-trace records, and checks total trace allocation events and requested bytes against the histogram. The print summary independently cross-checks the allocation-event count.

The diagnostic separates `total_allocations` for the complete process from `conversion` allocations whose complete trace ancestry contains `convert_shape_to_escher_with_sound_mapping`. Inline function IDs from each instruction record are included before walking parent traces, so an inlined conversion is attributed by its full ancestry. The returned comparison preserves allocation events, requested bytes, deallocation events, and deallocated bytes for both legs and their deltas. This is allocation-site evidence only; the historical 0753 plaintext-clone share is motivation and is never substituted for current evidence.

The probe is intentionally byte-identical to the corrected 0781 probe: `probe-inheritance.json` binds all five frozen probe files, while reports retain the 0781 schema, tool identifier, authored fixture identity, and allocator instrumentation identifiers. The observer itself binds those report identities while requiring the 0782 plan and observer-plan schemas, new packet paths, new build/source receipts, and the explicit candidate source allowlist. Observer analysis remains incomplete until both Heaptrack decode receipts are present and bound to their captured traces; no `observer-analysis.json` is created by this hook.
