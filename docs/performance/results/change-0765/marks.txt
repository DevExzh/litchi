# Which marked members kept their mark (change 0765)

Each differential scenario runs on a package whose XML members carry a mark, as
given and indented. "dropped" lists the marked input members whose published
output has no mark; every other marked member kept it. A dropped member is still
byte-identical to the unmarked twin's output. The only drops are parts the
library regenerates from a model.
