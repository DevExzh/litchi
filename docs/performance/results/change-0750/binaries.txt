rustc 1.95.0, which the repository's rust-toolchain.toml pins for builds in a
checkout; all four probe binaries by rustc 1.98.1, the host default, because
the probes were built from scratch directories outside the checkout. Each pair
of legs therefore used one compiler. The harness reports carry the same binary
SHA-256 in binary_identity.binary_sha256; their environment.rustc_version is the
rustc of the directory the harness ran from (1.95.0 for the timing runs, which
ran in the worktree; 1.98.1 for the callgrind runs, which ran in scratch), not
the compiler that built it.
