## Follow-up hypothesis: the upfront-stopped pair audit

The matched 0901 profile reports `verify_source_replacement` at 6.315 million self Ir out of 104.4 million inclusive Ir; `prepare_topology_state` is 61.4 million and the preservation writer 42.7 million. Source review identifies one narrow, disjoint hypothesis inside that audit. At `crates/xml-minifier/src/audit.rs:1056-1065`, the common prefix/suffix calculation marks `WindowSearch::stopped` before the original scan when the differing span alone is more than half the replacement. For the scattered one-percent parts, no usable window can pass `Window::prove` under that same half-size rule.

Even with that flag already set, the current code calls `verify_observed` with `WindowSearch`. Each token still reads `observer.listening()` and selects the false arm that supplies `Counters::default()` (`audit.rs:1923-1931`), then tests the listening flag before skipping `WindowSearch::accepted` (`audit.rs:2076-2078`). The observer performs no search work after the upfront stop, but the generic observer gate remains in the token loop. `verify_source` reaches the same source-policy scan through `verify_with_policy` with the unit observer `()`; its `listening` method is a compile-time false specialization (`audit.rs:1761-1769`, `2150-2190`).

A bounded candidate is therefore to branch on the already-known half-size condition before calling `verify_observed`: run `verify_source(original, limits)` first, map its failure to `ReplacementError::Original`, then run `verify_source(replacement, limits)` and return `ReplacementProof::Complete` or `ReplacementError::Replacement`. This preserves the current two-audit order, exact source-policy errors and offsets, limits, and no-window result. It must apply only to the upfront condition. A stop reached later by `WindowSearch` (for example allocation failure or an unsuccessful search) is a different state and should retain the current path; a differing span at or below half the replacement also retains window search.

This is a source hypothesis, not a speed claim. The 0747 implementation already added the half-size flag and the post-window observer gate (commit `90d5b19714`); its evidence measured the one-cell route and a small complete/no-window workbook pair, but did not isolate the upfront-stopped one-percent route. The 0750 Callgrind pairs likewise measured one-edit `verify_source_replacement` and separate `verify_source`, not this branch. A matched before/after Callgrind capture or microprofile is required before treating the hypothesis as an optimization.

## Semantic constraints for any follow-up

`verify_source_replacement` must retain source-first failure ordering, exact diagnostic offsets, source-policy structural checks, UTF-8/DTD/document-element checks, namespace and depth invariants, and aggregate budgets. Its window shortcut is valid only for the checked common-prefix/suffix and must force a complete scan when a new check needs offset, ordinal, or `xml:space` state. 0747 explicitly found that original auditing remains necessary; publication tests also show that semantic readback is not a replacement for malformed-XML auditing.

The preservation path must retain source member order, local and central framing, compression metadata, timestamps, unknown fields, untouched bytes, source freshness checks, ZIP64/opaque/encrypted refusal rules, and output-limit/error semantics. Copied members remain raw source ranges. Replacement emission order and framing are controlled by the preservation plan even when Deflate tasks run through an explicit session.

0837 and 0838 constrain compression changes: the durable inverse gate failed for a fresh-only compression policy because decompressed members do not reconstruct original compressed bytes. Opened-package/source-backed compression must therefore remain unchanged unless a physical-restoration design and provenance guarantee are established. Runtime codec dispatch is not evidence for changing that policy. Any Deflate optimization must preserve the current replacement method, deterministic emission order, CRC and size accounting, cancellation, worker/memory budgets, and sink behavior.

Relevant accepted decisions are ADR 0006 (preserve untouched physical details and audit XML), ADR 0011 (OPC owns physical package translation), ADR 0030 (lazy source payloads and proof for changed payloads), and ADR 0031 (execution-context budgets and no hidden global pool). The 0747 source-audit reuse report and 0837/0838 durable-inverse reports are the controlling prior performance evidence.
