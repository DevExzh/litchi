Each record compares the same API route and workload in one baseline campaign and its matching candidate campaign. Native rows were validated through `capture.validate`; profile and hardware lanes are excluded.
All phase metrics are in nanoseconds and use nearest-rank p50/p95/p99 plus arithmetic mean over 60 measured rows. RSS is the one whole-child GNU time maximum in KiB.
The p50 intervals use a fixed seed `5343761` and 4000 unpaired route bootstrap iterations. Each route is resampled within each internal repeat, then candidate median / baseline median is calculated. The two internal repeats are not independent processes, so intervals are descriptive only. RSS has no phase-local bootstrap because each child contributes one high-water observation.
