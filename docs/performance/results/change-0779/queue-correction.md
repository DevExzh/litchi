# Queue correction

The ZIP-2 first-read span work is already complete in the current tree. Change 0611 added the bounded member-span read in `soapberry-zip`, including physical and directory bounds, `SpannedSource` coverage fallback, preserved ZIP error behavior, and the associated differential and focused tests. Change 0623 added bounded structural prefetch for OPC catalog members, and change 0632 added central-directory/directory prefill. These changes cover the ZIP first-read and locate optimizations described by the older queue entry.

Consequently, the 0778 `next-step.md` recommendation to redo ZIP-2 is stale and should not be selected as a new implementation task. The residual adjacent idea is operation-scoped coalescing for a known unmanaged sequential part batch: merge only touching admitted `local_span_hint` runs, use temporary prefetch, and release it at the operation boundary. It remains unselected because cache-hit planning, concurrent-flight behavior, source-version fences, speculative-read accounting, error precedence, malformed/sparse span fallback, and managed-budget semantics need a new differential before implementation. The current 0779 investigation instead concerns OPC `read_limited` allocation attribution.
