## 0760 — a commit's recapture stops rescanning the slides it did not rewrite

[0760](0760-pptx-slide-root-memo-reapply.md) re-applies change 0743's withdrawn slide-root memo under ADR 0032, which the owner accepted on 2026-09-24 (0758 decision 1). `Transaction::commit` captured the staged package from scratch, and every capture classifies each slide root with the complete notes-graph scan, although the staged package shares the payload allocation of every slide the transaction did not rewrite. A snapshot now keeps the classifications its capture proved, keyed by allocation identity with a strong reference; a commit's recapture reuses them for untouched slides and scans only the rewritten ones. On the 100 × 100 deck the one-edit commit phase falls 21.19 → 1.61 ms (−92.4%; instructions −93.3%) and `pptx_semantic_one_edit_save` 45.88 → 26.77 ms (−41.8% [−42.9%, −41.0%]); medium one-edit −12.6%. The large one-percent case rewrites every slide and is unchanged (−0.09%), as are the no-op case and the full-text control, all inside the same session's A/A floor. What remains in the commit (1.57 ms, profiled): per-slide MCE preprocessing checks, the rewritten slide's scan, the presentation-level notes-graph load, slide-reference resolution, compaction, and a `Capabilities::ooxml_baseline()` hash set rebuilt on every MCE call (about 7.5%). A fresh capture still scans every slide (23.7 ms on this deck): the facade keeps no slide-root memo, which ADR 0032 would allow as a follow-up. [Evidence](results/change-0760/README.md).

## 0760 — the slide-root memo returns under ADR 0032: one-edit PPTX edit/save −41.8% on the large deck

[0760](0760-pptx-slide-root-memo-reapply.md) is retained with `performance_claim: none`. Seven >5% pair ratios are all p95 or mean tails, five from one time-shared process. Published archives, patches, revisions and full text are byte-identical, and a base-versus-head differential over 67,790 packages and 340,198 outcome lines matched exactly. No public API, durable format, limit or published byte changes; every capture (including the cross-copy, removal and patch captures, which build a memo without consulting one) can now also fail with a typed `Error::Allocation` if its memo cannot be reserved. ## For `GOAL_AUDIT.md`

## 0760 — a withdrawn memo returns only after its ADR is accepted, with every condition proven by a test

[0760](0760-pptx-slide-root-memo-reapply.md) implements what ADR 0032 admits and nothing more. The memo 0743 withdrew returns with the three changes ADR 0032 requires: a refused reservation is the typed `Error::Allocation` (raised after every validation, so it can only replace a success), never a silently empty table — the original's second silent fallback, an intermediate record vector, is gone; and only classifications the scan returned are kept, so a refusal is always recomputed from the bytes. The review added one more: the memo is built only from proofs that borrow the classified bytes, so the compiler proves each classified allocation alive while its entry is admitted — a lifetime-free record, which the reviewer showed could name a freed and reused address in a hand-built call, no longer exists — and the memo is not `Clone`, so it reaches another snapshot only by projection. The rebind projection keeps the digest projection's empty-memo degradation, as ADR 0032 section 3 specifies. Each condition of ADR 0005's memo amendment has a behavioural test: strong keys that cannot be recycled, entries only for the owning package's allocations, projection rather than inheritance on rebind, value, refusal and byte independence from memo contents (full, empty and partial memos), no mutation after construction, a bounded 32-byte-entry cost, the typed refusal leaving no partial snapshot, facade or published byte, and debug re-derivation of every hit — including a planted wrong classification that the re-derivation catches. The facade retains no such memo, which a test also shows. Three pre-existing all-features golden failures in the cross-copy tests, identical at the base, are reported rather than fixed. [Evidence](results/change-0760/README.md).
