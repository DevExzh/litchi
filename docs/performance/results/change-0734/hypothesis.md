# 0734 PPT owned stream payload pilot

0733 identified 384,906 bytes copied into CFB writer payloads on the qualified
45543 workflow. Transfer the existing owned buffers to create_stream_owned,
retaining all source/layout, output-limit, pre-sink and post-sink validation,
public reopen, semantic readback and patch digest requirements. No cache,
execution policy, public API or save-policy change is proposed.

Build the unchanged baseline first. Qualify the primary against the sealed
0728 oracle and select a second fixture from a fixed list using semantic and
preservation success only, retaining failed attempts. Build the final candidate
from the identical probe source and flags. Before the comparative matrix,
require byte-identical output, inventory and semantic witnesses on both cases.

Run three cycles, three paired rounds per cycle, both cases and both variants:
36 native processes, 50 samples and three warmups each. Rotate pair order by
cycle/round/case. Then run three allocation repeats per case and variant:
12 processes, one measured owner and no warmup each. Pin CPU 12, serialize all
execution, retain all samples/tails and do not selectively rerun. A synthetic
schema preflight must pass before main capture.

Flag each absolute paired p50/mean difference above 5%. Report all flags,
paired median changes and deterministic bootstrap intervals across the nine
process pairs per case; sample owners are not independent process repeats.
Retain only with a concrete allocation/work benefit and an explicit assessment
of every latency and peak-memory regression. Expected allocation work removes
at least the selected output stream payload byte count and five payload
allocations on the primary; this is a hypothesis to check, not a saving claim.
Peak live-byte growth above 5% is a review trigger. No RSS, cold-I/O, instruction,
concurrency or broader producer claim is made from this matrix.
