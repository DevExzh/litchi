Scope
-----

The candidate changes only existing workbook calculation metadata. It does not
support cell/formula/result edits, calculation-chain creation/removal, Part or
relationship topology changes, signature stripping, or general XLSX output.
The physical archive must satisfy the existing source-backed one-Part overlay
contract. Source read bytes remain archive-sized because unchanged compressed
members are copied to the output; the removed work is semantic materialization,
logical-byte ownership, validation of unrelated Part payloads, and
decompression/recompression of eleven untouched Parts.
