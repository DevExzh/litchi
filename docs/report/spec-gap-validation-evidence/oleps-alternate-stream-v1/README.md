# OLEPS alternate-stream metadata

AlternateStreamControl parses and writes the exact 8-byte or 24-byte control packet from local MS-OLEPS §2.24.3. It validates the required-zero reserved word, preserves the ignored source reserved word, and exposes inert application state and optional CLSID. Fresh values zero reserved fields; typed state/CLSID edits preserve source reserved bytes, including when adding or removing the CLSID.

NonSimpleAlternateStreamName represents the §2.24.5 Docf_ filesystem alternate-stream selector separately from a CFB directory path. It accepts the case-insensitive ABNF prefix, writes its canonical spelling, and retains the required binding-name control character. Fixed-size name storage avoids allocation during construction and inspection. Name identity normalizes special-FMTID aliases, including the ambiguous user-defined/document-summary spelling; the binding accessor reports the canonical name-only identity. No filesystem lookup, class activation, payload execution, or non-simple CFB storage editor is introduced.
