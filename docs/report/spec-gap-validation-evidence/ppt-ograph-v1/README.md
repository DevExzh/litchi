Bounded Graph chart authoring and PPT embedding
=============================================

The 18 source paths were reviewed independently and validated on integration base `22ba76ce61543c3ae3506ae64762194b5a1ddf5b`. Root tests passed 1,314 cases across 36 targets with 11 ignored; strict Clippy, warning-denied rustdoc and owned-file formatting passed. Author all-target and doctest logs are retained separately.

Supported authoring is standalone Graph Bar, stacked Line and axis-free Pie, including literal datasheet caches, PPT object identity closure and source-bound cache replacement. Excel-hosted charts, mixed or secondary axes, arbitrary parsed-chart mutation, rendering, evaluation, native Office acceptance and PhotoAlbum remain outside this batch.

Gzip archives preserve exact source manifests, patch, review and logs. `publication.json` binds raw and compressed hashes and final source bytes.
