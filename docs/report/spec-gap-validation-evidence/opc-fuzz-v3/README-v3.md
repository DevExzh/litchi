These are raw fuzz diagnostics only; the bundle makes no performance or timing claim.

`receipt-v3.json` is the machine-readable result. `corpus-manifest-v3.json` hashes every final on-disk corpus file. `smoke-v3-rerun.log`, `clippy-v3-rerun.log`, `rustfmt-v3-final.log`, `diff-check-v3-final.log`, `fuzz-build-v3-final.log`, and `fuzz-run-v3-final.log` are the final validation logs. Tool installation and seed setup history, including any surrounding `tooling.log`, is excluded from validation claims.

The harness only parses caller-provided bytes, performs bounded in-memory OPC operations, and treats external targets and embedded content as inert. It does not resolve ambient filesystem paths, fetch network resources, or execute macros, VBA, ActiveX, or OLE content.
