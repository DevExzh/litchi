# OfficeCLI capability delta (generated)

Generated by `tools/officecli_capability_delta.py`; do not edit by hand.
It compares OfficeCLI's help schemas with Litchi's golden capability
reports (`Capabilities::of(format)`, record 0010 §7), for the formats
OfficeCLI describes. M1 is read-only, so a property counts as supported
when Litchi reads it; OfficeCLI's add/set/get flags are shown as `asg`.
XLSB is compared against the XLSX help vocabulary as Litchi's parity
target; this does not claim OfficeCLI itself supports XLSB files.
DOCX operation gaps also include the feature-specific encryption baseline
when that golden is present.

Rerun the script after blessing the goldens (`LITCHI_BLESS=1`), for
example when an adapter lands; `tools/test_officecli_capability_delta.py`
fails while a golden differs from the hash recorded below.

## Statuses

| Status | Meaning |
|---|---|
| supported | Litchi reads it (a property, or the node's text for a predicate key such as a cell's `value`) |
| gap | Litchi lists it in `capabilities()` as a gap, with the follow-up shown |
| element gap | a property of an element Litchi lists as a gap |
| folded | an OfficeCLI element Litchi models inside another element (named in the follow-up) |
| pending | the format's adapter has not landed (the follow-up names its M1 step) |
| write-only | OfficeCLI cannot read it either (no `get`); M2's write surface decides |
| raw-only | native selection metadata excluded from ordinary APIs by ADR 0034 |
| operation gap | an element operation refused for a particular selection or leaf context; listed in the contextual gap table |
| missing | OfficeCLI reads it and Litchi neither reads nor lists it: untriaged |
| out of scope | not an element of the unified read surface |
| litchi-only | Litchi reads it and OfficeCLI's schema lacks it |

These operation gaps apply only to the named selection or leaf context; ordinary element operation support remains in the capability report.

| Verb | Element | Context | Reason | Follow-up |
|---|---|---|---|---|
| `create` | `presentation` | `template` | native PPTX template creation is not integrated | M2 PPTX creation options |
| `create` | `presentation` | `strict` | native PPTX Strict creation is not integrated | M2 PPTX creation options |
| `create` | `presentation` | `metadata` | initial unified PPTX metadata authoring is not integrated | M2 PPTX creation options |
| `add` | `shape` | `non-append-placement` | PPTX shape creation currently supports append placement only | M2 PPTX non-append shape placement |
| `add` | `shape` | `non-slide-parent` | text-box creation requires a top-level slide parent; group, master and layout insertion remain pending | M2 PPTX group/master/layout shape creation |
| `move` | `slide` | `positional-owner` | source-backed PPTX slide ordering still refuses sections, outline slide lists, numeric presentation ranges, and unknown or opaque metadata extensions | M2 PPTX positional-owner slide ordering |
| `swap` | `slide` | `positional-owner` | source-backed PPTX slide ordering still refuses sections, outline slide lists, numeric presentation ranges, and unknown or opaque metadata extensions | M2 PPTX positional-owner slide ordering |
| `remove` | `slide` | `dependency-topology` | native PPTX slide removal currently admits only a dependency-free slide with exactly one layout relationship; notes, comments, images, media, and external or internal relationship closure remain pending | M2 PPTX dependency-aware slide removal |
| `remove` | `slide` | `final-slide` | native PPTX slide removal currently preserves the final slide and cannot remove the last slide from a presentation | M2 PPTX final-slide removal policy |

| `set` | `shape` | `native-shape-text-preservation` | text replacement requires an existing slide shape text body and native edit admission; master/layout shapes, text-body creation and rich-text formatting remain pending | M2 PPTX structural and rich-text editing |
| `set` | `presentation` | `managed-signature-removal` | explicit signature removal requires native eager materialization, which managed sources refuse | M2 PPTX managed source-preserving signature removal |
