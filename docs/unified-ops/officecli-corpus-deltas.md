# OfficeCLI example-corpus deltas

Generated by `python3 tools/officecli_corpus.py` from
`crates/litchi-cli/tests/officecli_corpus/outcomes.tsv` (record 0265); do not edit by hand.
Regenerate after re-recording the outcomes:

```sh
LITCHI_BLESS=1 cargo test -p litchi-cli --test officecli_corpus
python3 tools/officecli_corpus.py      # --check verifies this file
```

The corpus is every OfficeCLI example script (`examples/{word,excel,ppt}/**/*.sh`, upstream commit `dced0d74ff`), vendored under `test-data/officecli/examples/` and replayed by `crates/litchi-cli/tests/officecli_corpus.rs` with `officecli` translated to `litchi` by `crates/litchi-cli/tests/officecli_corpus/officecli`. A line counts once per call, so a line inside a loop or a shell function counts each time it runs.

Kinds:

- **passed**: `litchi` exited 0. *Translated* lines needed a recorded translation first (delta D4).
- **gap**: Litchi lacks the verb, option, path form, element or property. Element and property refusals are cross-checked against the registry export (`crates/litchi-ops/tests/golden/registry/<format>.json`, the golden of `schema()`, which `capabilities()` shares): the note says what the registry records.
- **delta**: a recorded difference, deliberate or caused upstream (table below).
- **cascade**: a path that does not exist because an earlier `add` or `batch` of the same script was refused.
- **bug**: a refusal of something the registry claims, or an unexplained failure; none may be a panic or `internal_error` (the test refuses those).
- **resident**: `open`/`close`, not run (delta D5).
- **read-back**: after each script the harness runs `view <file> text` and `get <file> / --depth 2` on every file the script created.
