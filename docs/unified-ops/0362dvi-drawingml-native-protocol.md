# 0362dvi — paired DrawingML raw qualification protocol

This record adds the source-fenced paired protocol and real endpoint adapters
for the five raw DrawingML lanes. The adapter constructs or edits each lane
through the shared `litchi-drawingml` APIs, then performs the bounded read,
write, mutation, replay, and refusal checks outside the timed region. The
paired runner remains the only component allowed to make a source-fenced
performance claim; the endpoint itself fails closed when an API route or
typed refusal is missing.

The reviewed plan is
`drawingml-additional-qualification-plan-0b8e1744d1.json`, whose SHA-256 is
`d671c2dbd793d6b1b68c0aae25def384d6ceb44169be93b7daf848d6f13044f9`.

## Workload contract

`tools/native_qualification/manifests/drawingml-raw.json` describes one
profile per lane. `drawingml_raw_paired_runner.py` materializes each profile
into the generic guarded native runner, retaining its Cargo path validation,
20-GB target/address-space limits, unrelated-process guard, fresh child
processes, and exact `baseline,candidate,candidate,baseline` order.

Each profile runs three warmups, five ABBA blocks, and twenty samples per leg;
the adapter must calibrate each accepted leg to at least 150 ms (target 500
ms). Normal and allocator probes are separate binaries. Allocator output is
non-claimable elapsed data and reports direct/reallocation bytes, live-balance,
incremental peak-live, and process RSS independently from normal timing.

The required matrix is small/near-limit/at-limit/over-limit/malformed input;
entry/read and `read_shared` where supported; source-preserving no-op and
changed commit; forward, inverse, and stale replay; bounded `Vec` write and
`write_to` sink; and preflight refusal before allocation or the first sink
write. Fidelity and typed-refusal checks are outside the timed region. The
tracked fixture descriptor contains meaningful mutations; large boundary
inputs are generated by a final adapter and are never committed as evidence.

The endpoint coverage is explicit: chart authoring/reader/writer plus
`formatcode2`; SmartArt data-model edits and drawing relationships; text-body,
SVG blip, model3d, and image-blip readers/writers; theme palette/font codecs,
`themeFamily`, and strict InkML actions; and custom geometry, color,
`formatcode2`, and transform codecs. The allocator binary wraps the system
allocator only in its own process and records direct allocation/deallocation,
reallocation old/new bytes, live balance, peak-live delta, conservation, and
independent RSS. No std-only stand-in or all-unavailable adapter is accepted.

The validator rejects missing rows, altered ABBA/sample thresholds, short
accepted legs, allocator elapsed claims, missing source/fixture bindings, or
a qualified report without API-backed fidelity and typed refusal receipts.
It also requires the complete sample timer sum, exact source/changed/inverse
hash receipts, preflight zero-write evidence, and allocator conservation with
separate direct/deallocated/reallocation-old/reallocation-new/live/peak
counters. An unavailable report remains a valid non-claim control for source
preparation tests, but the real endpoint never emits one for a lane it was
asked to run.

Preparation (no Cargo or native execution) is performed per profile:

```sh
python3 tools/native_qualification/prepare_drawingml_raw_inputs.py \
  --baseline-root /external/sources/dml-chart-before \
  --candidate-root /external/sources/final-candidate \
  --baseline-revision 2d330c3305b79da79cd924bf371d2941b7f14cc4 \
  --candidate-revision "$FINAL_CANDIDATE_SHA" \
  --perf-lock-sha256 "$DRAWINGML_CHART_PERF_LOCK_SHA256" \
  --output /external/native-final/dml-chart-preparation.json
```

After all five receipts and external targets are ready, the coordinator may
run the guarded phases with the corresponding `DRAWINGML_*` environment
bindings:

```sh
python3 tools/native_qualification/drawingml_raw_paired_runner.py \
  --manifest tools/native_qualification/manifests/drawingml-raw.json \
  --phase build --cpu "$CPU"
python3 tools/native_qualification/drawingml_raw_paired_runner.py \
  --manifest tools/native_qualification/manifests/drawingml-raw.json \
  --phase abba --cpu "$CPU"
```

Outputs, binaries, targets, logs, and measurements remain external. Only a
small reviewed receipt may be committed later; no benchmark binary or large
raw evidence belongs in this repository.
