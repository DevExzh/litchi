# 0006 — Owner accepts ADR 0033

On 2026-10-04 the project owner accepted ADR 0033 (unified operations API over
the per-format owners) with the words "ADR 0033 accepted, proceed with M0a".

Effect: ADR 0033 moves from the proposed list to the accepted index in
`docs/adr/README.md`; M0a (flat `File`, single `litchi::open()`, unified error)
and later milestones may cite it as authority. The tier order recorded in the
goal (OOXML → legacy OLE → delayed RTF/ODF/iWork) is part of the accepted
context via the goal's owner override.
