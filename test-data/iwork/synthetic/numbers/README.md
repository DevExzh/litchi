# Synthetic Numbers benchmark grid (record 0297)

`9c17aba05afe42dd03ae048a42b94974abdaef7368d9ea207b40c277ca38582a`) is a
test-only package for `crates/litchi-ops/examples/numbers_unified_bench.rs`.
It holds one sheet `Bench` with one 101 x 11 table `Grid`: row 1 holds the
headings `C1`..`C10` in columns B..K, column A holds `R1`..`R100`, and the
rest is empty. No Numbers corpus fixture has a table of 1000 cells, which the
1000-cell batch scenario needs.

It was generated by a throwaway example run against the litchi-iwa migration
host (deleted by record 0429; last present at commit `27b4840684`): `litchi_iwa::numbers::Builder::new().sheet_name("Bench").table_name("Grid")
.table_dimensions(101, 11).build()`, then one
`litchi_numbers::Package::edit_table_cells` commit of the 110 labels. The
builder draws a fresh document identity, so regeneration gives different
bytes. It was not created by Numbers, carries no formula-owner dependency
records (formula authoring refuses on it), and must not be used as evidence
of native application compatibility.
