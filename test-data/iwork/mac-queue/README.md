# macOS-queue host-built inputs (manifest only)

Many checks of the macOS verification queue (native open/save/close/reopen in
Pages, Keynote and Numbers) ran on packages that the `litchi-iwa` host built at
test time (for example "`chart-data-native.numbers` + host-added Column2d
chart"). The host has been deleted, so those inputs can no longer be rebuilt,
and a rebuild would differ anyway: the host drew random object and document
UUIDs.

The inputs are the ones behind the packages of the queue's Mac runs: 797
packages, 181,143,941 bytes in total (largest 803,216 bytes). They are too
large to commit and stay outside the repository; this directory holds only
their manifest.

- [`host-built-inputs.tsv`](host-built-inputs.tsv): one row per input:
  SHA-256, path in the generator's output (`inputs/<sha256-prefix>.<ext>`),
  size, the parity fixture it was described as, and the parity cases that
  used it. It is a byte copy of the generator's `host-built-inputs.tsv`
  (SHA-256 `ee630a4f2a4897db2d273426c0452ad461a591a7c50adff689194ad0c1d68a7f`).
- The generator has been removed with the queue it served, and its output
  kept no parity dumps, so the manifest cannot be regenerated.
- License: generated by this repository's own code from its tracked fixtures
  (see `test-data/iwork/README.md` for their provenance).
