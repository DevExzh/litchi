# macOS-queue host-built inputs (manifest only; records 0429 and 0430)

Many rows of the macOS verification queue
([`docs/unified-ops/0363-mac-queue.md`](../../../docs/unified-ops/0363-mac-queue.md))
run on packages that the `litchi-iwa` host built at test time (for example
"`chart-data-native.numbers` + host-added Column2d chart"). Record 0429 (W3)
deletes the host, so those inputs can no longer be rebuilt, and a rebuild
would differ anyway: the host draws random object and document UUIDs.

The inputs are the ones the record 0430 generator (`tools/mac_queue/generate.py`)
used for the packages sent to the Mac: 798 packages, 181,281,065 bytes in
total (largest 803,212 bytes). They are too large to commit and stay outside
the repository; this directory holds only their manifest.

- [`host-built-inputs.tsv`](host-built-inputs.tsv): one row per input:
  SHA-256, path in the generator's output (`inputs/<sha256-prefix>.<ext>`),
  size, the parity fixture it was described as, and the parity cases that
  used it. It is a byte copy of the generator's
  `.coord/mac-runbook/out/host-built-inputs.tsv`
  (SHA-256 `138375655ec2f48bac7d500a62db74517923c0a668fdbf74f3f1971da59aa492`).
- Generator run: source commit `b9c6051c0a` (record 0430, merged into trunk
  at `2d74fc4d06`), `cargo test -p litchi-iwa --all-features --test parity`
  with its dump hook; output manifest
  `.coord/mac-runbook/out/manifest.json`, SHA-256
  `56628e2d5ab64d32992953d114eb20a17519df08b01196f2b730533dc2f323e6`
  (766 rows, 1,153 packages).
- Bytes, on the Linux host (not committed): the generator output
  `/home/zhuhe/code/litchi-worktrees/.coord/mac-runbook/out/inputs/`, and a
  verified copy (all 798 SHA-256 values match this manifest) in
  `/home/zhuhe/code/litchi-worktrees/.coord/iwa-w3/mac-inputs/`.
- After W3, `tools/mac_queue/generate.py` cannot run the host; it regenerates
  the queue packages only from the frozen dumps
  (`--reuse-dumps --out .coord/mac-runbook/out`). Do not regenerate `out/`
  between the Mac run and the merge of W3.
- License: generated by this repository's own code from its tracked fixtures
  (see `test-data/iwork/README.md` for their provenance).
