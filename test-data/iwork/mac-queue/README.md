# macOS-queue host-built inputs (manifest only; record 0429)

Many rows of the macOS verification queue
([`docs/unified-ops/0363-mac-queue.md`](../../../docs/unified-ops/0363-mac-queue.md))
run on packages that the `litchi-iwa` host built at test time (for example
"`chart-data-native.numbers` + host-added Column2d chart"). Record 0429 (W3)
deletes the host, so those inputs can no longer be rebuilt, and a rebuild
would differ anyway: the host draws random object and document UUIDs.

The inputs are the ones behind the packages of the queue's Mac evidence
(records 0433 and 0434): 797 packages, 181,143,941 bytes in total (largest
803,216 bytes). They are too large to commit and stay outside the repository;
this directory holds only their manifest.

- [`host-built-inputs.tsv`](host-built-inputs.tsv): one row per input:
  SHA-256, path in the generator's output (`inputs/<sha256-prefix>.<ext>`),
  size, the parity fixture it was described as, and the parity cases that
  used it. It is a byte copy of the generator's
  `.coord/iwa-w6/queue-out/host-built-inputs.tsv`
  (SHA-256 `ee630a4f2a4897db2d273426c0452ad461a591a7c50adff689194ad0c1d68a7f`).
- Generator run: source commit `d3f8b897ac` (record 0433), the record 0430
  generator with the parity harness's dump hook; output manifest
  `.coord/iwa-w6/queue-out/manifest.json`, SHA-256
  `6d59fef38bb0900568c337743bcde98aad0169d4bbf55e8a6a3370f7b98d045a`
  (767 rows, 1,160 packages), the manifest record 0434 folded against.
- Bytes, on the Linux host (not committed):
  `/home/zhuhe/code/litchi-worktrees/.coord/iwa-w6/queue-out/inputs/`. Do not
  delete `.coord/iwa-w6/`, `.coord/mac-runbook/out*` or
  `.coord/iwa-w3/mac-inputs/` (the 798 inputs of the record 0430 run).
- Without the host, `tools/mac_queue/generate.py --check` maps rows, and the
  `mac_queue_file_routes` and `mac_queue_native_routes` examples still run. The
  generator's output kept `inputs/`, `packages/` and `manifest.json` but not its
  parity dumps (`raw/` holds only `example/`), so the manifest cannot be
  regenerated; it stands as the record of the run. Do not point `--out` at it.
