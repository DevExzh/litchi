# XLSX form-control property corpus index

`native-corpus.json` lists the form-control parts (member name, size and
SHA-256) observed in existing LibreOffice spreadsheet fixtures. It holds identities and metadata only, no fixture bytes. The
`litchi-xlsx` `form_control_*` tests compile it in. It moved here from
`docs/report/spec-gap-validation-evidence/xlsx-form-control-properties/`.

- Upstream of the indexed fixtures: LibreOffice core
  (<https://git.libreoffice.org/core>), under `sc/qa/unit/data/xlsx/`; each
  entry records its upstream path.
