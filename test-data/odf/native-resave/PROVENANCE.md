26.2.5.2 produced their counterparts in `libreoffice-resaved/`. Each
derivative retains the license of its source package.

| Format | Source |
| --- | --- |
| Text | `test-data/odf/corpus/writer-header-footer.odt` |
| Spreadsheet | `test-data/odf/corpus/calc-two-sheets.ods` |
| Presentation | `test-data/odf/odp/tdf169979.odp` |
| Formula | LibreOffice core, `starmath/qa/cppunit/data/font-styles.odf` |
| Drawing | LibreOffice core, `sd/qa/unit/data/odg/rhbz1870501.odg` |

The Formula and Drawing originals are under `source/` with the MPL-2.0
license from LibreOffice core's `COPYING.MPL`.
