# ODFDOM chart fixtures

`OdfdomChartProducer.java` uses ODFDOM 0.13.0 from the ODF Toolkit
(<https://odftoolkit.org/>, Maven group `org.odftoolkit`) to create
`odfdom-created.odc`, then load, edit, and save `odfdom-resaved.odc`. The
producer is licensed under Apache-2.0. The packages retain the license
notice from ODFDOM's bundled chart template.
